# Задание 4. Доступность (a11y), клавиатурная навигация и GitHub Actions CI/CD

## Что сделать:
- Проверить и обеспечить соответствие стандарту доступности WCAG AA (Lighthouse Accessibility = 100):
  - Контрастность текста не менее 4.5:1 для обычного текста и 3:1 для крупных элементов;
  - Все поля ввода имеют связанные элементы `<label htmlFor="...">`;
  - Интерактивные элементы (кнопки тегов, ссылки, чекбоксы) имеют видимый и контрастный фокусный контур (`:focus-visible`);
  - Доступные атрибуты `aria-live="polite"` на счётчике новостей;
  - Семантическая разметка (`<header>`, `<main>`, `<article>`, `<h1>`, `<h2>`, `<time>`, `<nav>`);
- Настроить конвейер непрерывной интеграции и публикации в `.github/workflows/deploy.yml`:
  - Установка зависимостей;
  - Проверка линтером с флагом строгой остановки: `npm run lint -- --deny-warnings`;
  - Запуск модульных и интеграционных тестов: `npm test`;
  - Сборка продакшен-бандла: `npm run build`;
  - Публикация в GitHub Pages.

## Готово, когда:
- `npx tsc -b` и `npm run lint -- --deny-warnings` — 0 ошибок и 0 предупреждений;
- `CI=true npm test` — все тесты успешно пройдены;
- Проверка клавиатурой (Tab / Shift+Tab / Space / Enter) проходит по всем элементам управления без «ловушек фокуса»;
- Workflow файл создан и протестирован на синтаксическую корректность.
