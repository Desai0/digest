# Задание 2. Поиск, фильтр по тегу и чекбокс «Только непрочитанные»

## Что сделать:
- Добавить панель фильтрации над лентой новостей:
  - Текстовое поле поиска по заголовку (`title`) и пересказу (`summary`) без учёта регистра с доступной подписью (`<label htmlFor="search-input">Поиск</label>`);
  - Выбор одного тега (кнопки-чипы тегов или select с тегами из загруженных новостей) с возможностью сброса;
  - Флажок (чекбокс) «Только непрочитанные»;
  - Счётчик отфильтрованных новостей: «Показано N из M новостей» с правильным склонением числительных (вспомогательная функция `plural`).
- Если ни одна новость не подошла под критерии — выводить сообщение `<p className="empty">Новостей не найдено</p>`.

## Правила проекта:
- **Отфильтрованный список новостей вычисляется при отрисовке** (производное состояние) и не хранится в `useState`. Запрещено синхронизировать отфильтрованный список через `useEffect`.
- Поиск, тег и флажок работают одновременно (комбинированная фильтрация).

## Готово, когда:
- `npx tsc -b` и `npm run lint -- --deny-warnings` — без ошибок;
- `CI=true npm test` проходит;
- В `src/App.test.tsx` добавлены тесты:
  1. Поиск: фильтрует карточки по совпадению слова в заголовке или пересказе;
  2. Фильтр по тегу: отображает только новости с указанным тегом;
  3. Сообщение «Новостей не найдено», когда фильтр отсекает все элементы;
- В браузере фильтрация работает быстро и плавно при вводе запроса.
