# Задание 3. Отметка «прочитано» и сохранение в localStorage

## Что сделать:
- Добавить в каждую карточку новости кнопку «Отметить прочитанным» (при повторном клике текст меняется на «Прочитано ✓», отметка снимается).
- Карточка прочитанной новости визуально выделяется (класс `.news-card--read`, более бледный вид, приглушенный фон).
- Список идентификаторов (`id`) прочитанных новостей сохраняется в браузере через `localStorage` под ключом `'digest_read_ids'`.
- При открытии и перезагрузке страницы отметки восстанавливаются из `localStorage`.
- Флажок «Только непрочитанные» скрывает карточки с активной отметкой «прочитано».

## Правила проекта:
- `localStorage` инициализируется при старте приложения без лишних повторных чтений на каждый рендер (`useState(() => loadReadIds())`).
- Запись в `localStorage` выполняется при изменении состояния прочитанных новостей.
- Кнопка должна иметь доступное состояние и корректный `aria-label` / `aria-pressed`.

## Готово, когда:
- `npx tsc -b` и `npm run lint -- --deny-warnings` — без ошибок;
- `CI=true npm test` проходит;
- В `src/App.test.tsx` добавлены тесты:
  1. Клик по кнопке отмечает новость прочитанной и меняет текст на «Прочитано ✓»;
  2. Повторный клик снимает отметку;
  3. Состояние прочитанности сохраняется в `localStorage` и восстанавливается после перезагрузки;
  4. Флажок «Только непрочитанные» скрывает новость сразу после отметки;
- В браузере после обновления страницы (F5) прочитанные новости сохраняют свой статус.
