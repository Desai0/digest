## Формат данных веб-приложения Apps Script (VITE_DIGEST_URL)
Адрес веб-приложения Apps Script возвращает объект `{ "news": [...] }`.
Каждый элемент в ответе содержит поля:
- `id`: string — уникальный идентификатор новости (URL без utm-меток)
- `date`: string — дата и время публикации в формате ISO 8601 (например, `"2026-11-19T08:30:00.000Z"`)
- `source`: string — название источника («Хабр», «3DNews», «iXBT»)
- `title`: string — заголовок новости
- `summary`: string — краткий пересказ новости от модели ровно в двух предложениях
- `tags`: string — **внимание**: Google Таблица и Apps Script возвращают теги строкой через запятую с пробелом (например, `"ИИ, наука"`). Функция загрузки данных обязана преобразовывать их в массив строк `['ИИ', 'наука']` с удалением пробелов по краям.
- `link`: string — прямая ссылка на полную новость

## Архитектурные правила
1. **Загрузка данных**: функция `loadDigest(url?: string)` в `src/digest.ts`. Читает адрес из `import.meta.env.VITE_DIGEST_URL`. Если ответ не `ok`, выбрасывает ошибку с текстом: `Дайджест не загрузился: код ${res.status}.`. Новости сортируются от свежих к старым по полю `date`.
2. **Состояния экрана**:
   - Пока идет загрузка — `<p role="status">Загрузка дайджеста…</p>`
   - При ошибке загрузки — `<p role="alert">Дайджест не загрузился: код N.</p>`
   - Если после фильтрации нет новостей — `<p className="empty">Новостей не найдено</p>`
3. **Фильтрация и состояние**:
   - Поиск по заголовку и пересказу без учета регистра
   - Выбор одного тега (клик по тегу фильтрует, повторный клик или кнопка сбрасывает)
   - Чекбокс «Только непрочитанные»
   - **Главное правило**: отфильтрованный список новостей вычисляется при отрисовке (производное состояние) и **ни в коем случае не синхронизируется через `useEffect`** в отдельное состояние!
4. **Отметка «прочитано»**:
   - Идентификаторы прочитанных новостей сохраняются в `localStorage` по ключу `digest_read_ids`.
   - Отметка переключается кнопкой и не пропадает после перезагрузки страницы.
   - Прочитанная карточка визуально выделяется (класс `.news-card--read`).
5. **Доступность (a11y)**:
   - Lighthouse Accessibility — 100/100.
   - Все поля ввода и элементы управления имеют связанные подписи (`<label htmlFor="...">`, `aria-label`, `aria-pressed`).
   - Полная доступность с клавиатуры (клавиши Tab, Enter, Space).
